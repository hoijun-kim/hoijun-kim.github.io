# hoijun-kim.github.io

My personal site - https://hoijun-kim.github.io

Static single page (plain HTML/CSS/JS). Edit `index.html`.

`favicon.svg` is the source of truth for the mark. `favicon.ico`,
`apple-touch-icon.png` and the Open Graph card `og.png` are generated from a
copy of its geometry - re-run `python tools/make-icons.py` (Pillow only) after
changing the mark, and keep the two geometries in step by hand.
